# Arabica

Original font files supplied by the project owner in `Arabica.zip`:

- `Arabica.otf`: from `Arabica file/otf/Arabica.otf` (Regular)
- `Arabica-Italic.otf`: from `Arabica file/otf/Arabica-italic.otf` (Italic)

The files are unmodified. Both contain Thai and Latin characters.

The supplied archive did not include a separate license document. Confirm that
your font license permits web embedding and distribution before publishing.
This project's code does not grant additional rights to these font files.

CSS loads the files from this project with `font-display: swap`. There is no
external font service or device installation requirement. No bold file was
provided, so the browser may synthesize bold weights used by the interface.
